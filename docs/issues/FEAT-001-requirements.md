# FEAT-001 商品検索機能強化 — 要件定義書

| 項目       | 内容       |
|------------|------------|
| Issue ID   | FEAT-001   |
| 作成日     | 2026-04-26 |
| ステータス | 定義中     |

---

## 1. 目的

商品検索のヒット率を上げ、離脱率を下げるため、ヘッダー検索ボックスを起点とする商品検索機能を強化する。

## 2. 対象範囲

ヘッダーの検索ボックスから遷移する **検索結果一覧画面**（`GET /products/search`）の **絞り込み条件パネル** と、それに紐づくバックエンドのクエリロジック。

カテゴリ一覧画面・商品詳細画面・バッチ・管理機能は対象外。

## 3. 現状実装

| 項目           | 内容                                                               |
|----------------|--------------------------------------------------------------------|
| 検索対象カラム | `product_name`、`product_variants.product_code`                    |
| マッチ方式     | `ILIKE` `%keyword%`（部分一致・大文字小文字区別なし）             |
| 正規化         | なし                                                               |
| フィルタ項目   | カテゴリ、在庫あり、価格帯、カラー                                 |
| 0件時の処理    | 「条件に一致する商品はありません」のみ表示                         |

## 4. 機能要件

### FR-001: 商品コード検索の絞り込み

商品コード（`product_variants.product_code`）の検索を **完全一致・前方一致のみ** に変更する。中間一致・後方一致はヒットしない。

| 入力例   | ヒット条件                     |
|----------|--------------------------------|
| `DSK001` | 完全一致（= `DSK001`）         |
| `DSK`    | 前方一致（LIKE `DSK%`）        |
| `001`    | ヒットしない（中間一致は除外） |

### FR-002: 検索対象フィールドの拡張

キーワード検索の対象フィールドを以下に拡張する。

| フィールド       | テーブル           | 備考                                |
|------------------|--------------------|-------------------------------------|
| `product_name`   | `products`         | 既存                                |
| `variation_name` | `products`         | `has_variation = false` の場合 NULL |
| `description`    | `products`         | TEXT 型（上限なし）                 |
| `product_code`   | `product_variants` | FR-001 の条件で検索                 |

**SQL パラメータ設計**

`keyword`（生値）と `keywordLike`（`%`囲み）の2パラメータに分離する。

| パラメータ名  | 値                  | 用途                                 |
|---------------|---------------------|--------------------------------------|
| `keyword`     | 入力値そのまま      | 商品コード検索（完全一致・前方一致） |
| `keywordLike` | `%` + 入力値 + `%` | 商品名・バリエーション名・説明文     |

```xml
<if test="keyword != null and keyword != ''">
  AND (
    p.product_name ILIKE #{keywordLike}
    OR p.variation_name ILIKE #{keywordLike}
    OR p.description ILIKE #{keywordLike}
    OR EXISTS (
      SELECT 1 FROM product_variants pvk
      WHERE pvk.product_id = p.product_id
        AND (
          LOWER(pvk.product_code) = LOWER(#{keyword})
          OR LOWER(pvk.product_code) LIKE LOWER(#{keyword}) || '%'
        )
    )
  )
</if>
```

### FR-003: 大文字/小文字の区別をしない検索

商品名・バリエーション名・説明文に `ILIKE`、商品コードに `LOWER()` を使用し、大文字小文字を区別しない。

### FR-004: 全角/半角の正規化（NFKC）

キーワード入力受け取り時に **Unicode NFKC 正規化** を適用する。

| 変換前（入力）    | 変換後        | 備考                 |
|-------------------|---------------|----------------------|
| `ＤＳＫ`（全角） | `DSK`（半角） | 全角英数字 → 半角    |
| `ｄｓｋ`（全角） | `dsk`（半角） | 全角小文字 → 半角    |
| `１２３`（全角） | `123`（半角） | 全角数字 → 半角      |
| `ひらがな`        | `ひらがな`    | ひらがなは変換しない |
| `！＠＃`（全角） | `!@#`（半角） | 全角記号 → 半角      |

> ひらがな・カタカナの相互変換は対象外。DB の正規化は不要。

### FR-005: テイストフィルタ（追加）

デスクトップサイドバーの絞り込みパネルに **テイスト** フィルタを追加する。

| 項目                 | 内容                                                                    |
|----------------------|-------------------------------------------------------------------------|
| 対象カテゴリ         | デスク・チェア・収納（各カテゴリの `*_tastes` テーブルを使用）         |
| リクエストパラメータ | `deskTaste`（複数可）、`chairTaste`（複数可）、`storageTaste`（複数可）|
| 表示方式             | カテゴリ別にグループ化して表示                                          |
| 他フィルタとの結合   | AND 結合                                                                |
| モバイル対応         | 今回はデスクトップサイドバーのみ対象（モバイルモーダルは対象外）       |

### FR-006: 既存フィルタ機能の維持

既存のフィルタ機能（カテゴリ、在庫あり、価格帯、カラー）の動作を変更しない。キーワードが空の場合は全商品を返す（現状維持）。

### FR-007: 0件時のおすすめ商品表示

検索結果が0件だった場合、おすすめ商品を最大8件表示する。

| 項目           | 内容                                         |
|----------------|----------------------------------------------|
| データソース   | `popular_product_rankings` テーブル          |
| 使用する集計日 | `MAX(ranking_date)` で最新ランキング日を取得 |
| 表示順         | `rank` 昇順                                  |
| 表示件数上限   | 8件                                          |

### FR-008: 入力バリデーション

キーワード入力は **100文字以内** でバリデーションを実施する。

## 5. 非機能要件

|----------|---------------------------------------|

| DB 負荷  | 既存の接続プールとスキーマの範囲内    |
