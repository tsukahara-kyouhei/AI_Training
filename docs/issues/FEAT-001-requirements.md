# FEAT-001 要件定義書 — 商品検索機能強化

| 項目 | 内容 |
|------|------|
| 課題ID | FEAT-001 |
| 作成日 | 2026-03-15 |
| ステータス | 確定 |

---

## 1. 目的

商品検索のヒット率を上げ、離脱率を下げることを目的として、商品検索機能の強化を行う。

---

## 2. 対象範囲

- ヘッダの検索ボックスから実行される検索機能
- 検索結果の一覧画面

---

## 3. 機能要件

### 3.1 商品コード検索

- 検索条件は **完全一致** または **前方一致** のみを対象とする。
  - 中間一致では商品コードの一部の数字が意図せず一致してしまう場合があるため、除外する。
- 完全一致・前方一致の判定はシステムが入力値の桁数で自動的に行う。
  - 入力文字数が **9文字以上** の場合：**完全一致**
  - 入力文字数が **9文字未満** の場合：**前方一致**
  - フォーマット（ハイフンの有無等）によるパターン判定は行わない。

### 3.2 商品名・シリーズバリエーション名・説明文の検索

- 以下のフィールドを対象に **部分一致検索** をサポートする。
  - 商品名（`product_name`）
  - シリーズバリエーション名（`variation_name`）※今回新規追加
  - 説明文（`description`）※今回新規追加

### 3.3 英字の大文字・小文字

- 英字については大文字・小文字を **区別せず** に検索できること。
- 正規化はJavaアプリケーションレベルで実装する。

### 3.4 全角・半角の正規化

- 数字・英字・カタカナについては全角・半角を **区別せず** に検索できること。
- 正規化はJavaアプリケーションレベルで実装する。
- **ひらがな** は正規化対象外とする（ひらがな↔カタカナ変換は行わない）。

### 3.5 検索結果画面の絞込条件（テイスト）

- 絞込条件に **「テイスト」** を追加する。
- テイストの表示仕様：
  - カテゴリ別（デスク・チェア・収納）のテイストマスタを統合し、**同一名称は1件にまとめて**表示する（全5種：ベーシック・カジュアル・シンプル・モダン・ナチュラル）。
- テイスト絞込時の検索挙動：
  - 選択されたテイスト名に合致するカテゴリの商品のみを検索対象とする（例：「ナチュラル」を選択した場合、`desk_tastes`・`chair_tastes`・`storage_tastes` のそれぞれで「ナチュラル」に合致する商品を対象とする）。
  - 複数のテイストを選択した場合は **OR条件**（いずれかのテイストに合致する商品を表示）とする。

### 3.6 キーワード入力の制約

- 検索キーワードは **1キーワードのみ** を受け付ける。
- スペース区切り等による複数キーワード入力は不可とし、入力値全体を1つのキーワードとして扱う。
- キーワード未入力時・最大文字数制限・0件時の表示仕様は現状の既存挙動を踏襲する。

### 3.7 既存機能の踏襲

- 上記以外については現状の商品検索の機能を踏襲する（既存仕様を維持する）。
  - ソート順（デフォルト・選択肢）
  - ページネーション・1ページあたりの表示件数

---

## 4. 性能要件

| 項目 | 目標値 | 備考 |
|------|--------|------|
| 検索対象商品数 | 最大 1,000 件程度 | |
| 一覧初回表示レスポンス | 95 パーセンタイルで **2 秒以内** | **サーバーレスポンスタイム**を基準とする |

- パフォーマンス向上のためのインデックス追加等は設計者の判断に委ねる。

---

## 5. 対象外

- 管理画面側の商品検索
- カテゴリ一覧ページ自体の検索ロジック（絞込条件の「テイスト」UI仕様は参照するが、変更は行わない）

---

## 6. 備考

- 全角・半角正規化および大文字・小文字正規化はJavaアプリケーションレベルで実装する。
- テイスト絞込のリクエストパラメータ名は実装時に任意で定義する。
- テイストマスタ（`desk_tastes` / `chair_tastes` / `storage_tastes`）は統合せず、各テーブルのまま参照する。UI上で同一名称をまとめて表示し、絞込時に全カテゴリをOR条件で検索する。
