# FEAT-003: 商品レビュー機能 要件定義書

## 1. 目的

- 商品検討時の情報不足を減らし、購入意思決定を支援する。
- 購入後フィードバックを蓄積し、商品改善・訴求改善に活用する。

## 2. 対象範囲

| 範囲 | 概要 |
|------|------|
| 商品詳細でのレビュー一覧表示 | 平均評価・件数・最新順レビュー一覧を商品詳細ページに表示 |
| ログイン会員のレビュー投稿/更新/削除 | 購入履歴のある商品に対し 1 会員 1 商品 1 レビューで投稿・更新・削除 |
| 商品一覧/詳細での平均評価・件数表示 | 一覧ページおよび詳細ページに平均評価と件数を表示 |

## 3. 機能要件

### 3.1 投稿権限

- ログイン会員のみ投稿可能とする。
- 対象の会員が実際に購入した商品（購入履歴のある商品）のみ投稿可能とする。
- 購入履歴の判定条件: `orders.order_status` が `cancelled` 以外の注文に含まれる商品を「購入済み」とみなす。
- 購入履歴の商品紐付け: `products.product_id` → `products.product_code` → `order_items.product_code` の関連で判定する。

### 3.2 投稿ルール

- 1 会員 1 商品につき 1 レビューとする。
- 投稿済みの場合は更新（上書き）とする。
- 投稿者自身によるレビュー削除を可能とする。

### 3.3 入力項目

| 項目 | 必須/任意 | 制約 |
|------|-----------|------|
| 評価 | 必須 | 1〜5 の整数 |
| タイトル | 任意 | 最大 100 文字 |
| 本文 | 必須 | 最大 1000 文字 |
| 公開状態 | 必須 | 登録・更新時に投稿者が選択（デフォルト: 公開） |

### 3.4 公開状態の管理

- 投稿者は登録・更新時に公開/非公開を選択できる。
- 管理者は管理画面からレビューの公開状態を変更できる。
- 管理者は「更新ブロック」フラグを設定でき、チェックボックスで切り替える。更新ブロックが有効なレビューは投稿者による更新・削除を不可とする。

### 3.5 表示要件

- 商品詳細ページに以下を表示する。
  - 平均評価（星表示）
  - レビュー件数
  - レビュー一覧（最新順、「もっと見る」形式のページネーション）
- 商品一覧ページに以下を表示する。
  - 平均評価
  - レビュー件数

## 4. 画面要件

### 4.1 商品詳細ページ（レビュー一覧セクション）

- レビュー一覧セクションを設け、最新順でレビューを表示する。
- 各レビューの表示項目: 評価、タイトル、本文、投稿日時。
- レビューが多い場合は「もっと見る」ボタンで追加読み込みする。
- ログイン会員かつ購入履歴ありの場合、「レビューを書く」ボタンを表示する。
- 購入履歴なしの会員には投稿ボタンを非表示とする。
- 投稿済み会員には「レビューを書く」ボタンに代えて「編集」導線を表示する。

### 4.2 レビュー投稿/編集フォーム

- 商品詳細ページ内にインライン表示する。
- 評価（1〜5）、タイトル（任意、最大 100 文字）、本文（必須、最大 1000 文字）、公開状態の入力フォームを表示する。
- バリデーションエラー時はメッセージを表示し再入力を促す。
- 投稿/更新成功時は商品詳細ページに戻る。

### 4.3 未ログイン時

- 投稿ボタン押下でログイン画面へ遷移し、レビュー処理は行わない。

### 4.4 管理者画面

- レビューの公開状態を変更できる。
- 「更新ブロック」チェックボックスにより、投稿者による更新・削除をブロックできる。

## 5. データ要件

### 5.1 レビューテーブル（reviews）

| カラム | 型 | 制約 | 説明 |
|--------|----|------|------|
| id | BIGSERIAL | PK | レビューID |
| member_id | BIGINT | NOT NULL, FK(members) | 会員ID |
| product_id | BIGINT | NOT NULL, FK(products) | 商品ID |
| rating | SMALLINT | NOT NULL, CHECK(1〜5) | 評価 |
| title | VARCHAR(100) | NULL許容 | タイトル |
| body | VARCHAR(1000) | NOT NULL | 本文 |
| is_published | BOOLEAN | NOT NULL, DEFAULT TRUE | 公開状態 |
| is_blocked | BOOLEAN | NOT NULL, DEFAULT FALSE | 管理者による更新ブロック |
| created_at | TIMESTAMP | NOT NULL, DEFAULT now() | 作成日時 |
| updated_at | TIMESTAMP | NOT NULL, DEFAULT now() | 更新日時 |

- UNIQUE 制約: `(member_id, product_id)` — 1 会員 1 商品 1 レビューを担保する。
- インデックス: `(product_id, created_at DESC)` — 商品別の最新順取得に使用する。

### 5.2 購入履歴との紐付け

- `products.product_id` → `products.product_code` → `order_items.product_code` の関連を用いて、会員の購入実績を判定する。
- `orders.order_status != 'cancelled'` の注文に含まれる商品を購入済みとする。

## 6. 非機能要件

- 商品一覧での平均評価・件数はクエリ負荷を考慮し、必要に応じて集計キャッシュまたはサマリカラムの導入を検討する。
