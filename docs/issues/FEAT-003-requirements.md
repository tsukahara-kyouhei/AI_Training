# 要件定義書: 商品レビュー機能追加 (FEAT-003)

## 1. 概要・目的
本機能は、ECサイトにおける商品レビュー機能の追加を目的とする。
* **購入意思決定の支援:** ユーザーが商品検討時に抱く情報不足を解消し、コンバージョン率の向上を図る。
* **フィードバックの活用:** 購入後のユーザーの声を蓄積し、商品開発やマーケティング訴求の改善に活用する。

## 2. 対象範囲
本プロジェクトのスコープは以下の通り。
* 商品詳細ページにおけるレビュー一覧・総合評価の表示
* 商品一覧ページにおける総合評価の表示
* ログイン会員による対象商品のレビュー投稿および更新
* (追加) 管理者によるレビューのモニタリングおよび非表示対応機能

## 3. 機能要件
### 3.1 ユーザー向け機能
* **レビュー閲覧**
    * 商品一覧・詳細ページに「平均評価（小数点第1位まで）」と「レビュー件数」を表示する。
    * 商品詳細ページの下部にレビュー一覧を表示する。
    * 並び順は「最新順」をデフォルトとする。
    * ※10件以上のレビューがある場合は「もっと見る」ボタンまたはページネーションを設ける。
* **レビュー投稿・更新**
    * **権限:** ログイン済みの会員のみに限定。未ログインの場合は投稿ボタン押下でログイン画面へリダイレクトさせる。
    * **投稿条件:** 対象会員が「過去に実際に購入した商品（購入履歴があるステータス：発送済み等）」のみ投稿可能とする。
    * **投稿上限:** 1会員につき1商品1レビューまで。既に投稿済みの場合は「更新（編集）」として扱う。
    * **入力項目:**
        * 評価（星1〜5の5段階）：必須
        * レビュー本文：必須（例: 最大1000文字）
        * レビュータイトル：任意（例: 最大50文字）

### 3.2 管理者向け機能 (追加要件)
* **レビュー管理**
    * 管理画面にて、投稿された全レビューを一覧で確認できる。
    * 規約違反や不適切な内容を含むレビューについて、管理者が「公開状態」を非公開に変更できる。

## 4. 画面・UI要件
* **未ログイン時の挙動:** 
    * 商品詳細ページのレビューエリアに「レビューを投稿する」ボタンを配置。
    * 押下時、未ログインの場合はログインページへ遷移させ、ログイン完了後に元の商品詳細ページへリダイレクトさせる（可能であれば入力情報を保持、または遷移のみ）。
* **購入未済の会員:**
    * ログイン状態であっても、対象商品の購入履歴がない場合は「この商品のレビューは購入者のみ投稿できます」といったメッセージを表示し、投稿フォームを非活性とする。
* **投稿済み会員の挙動:**
    * ログイン状態で、既に当該商品のレビューを投稿済みのユーザーがアクセスした場合、「レビューを編集する」導線（ボタン）を表示し、既存の入力内容が入った状態でフォームを展開する。

## 5. エラー・バリデーション要件 (追加要件)
* **未入力エラー:** 必須項目（評価、本文）が未入力の場合、送信時にエラーメッセージを表示。
* **文字数制限:** 
    * 本文が1000文字を超える場合エラー。
    * タイトルが50文字を超える場合エラー。
* **不正操作防止:** 購入履歴のないユーザーが直接API等を叩いて投稿しようとした場合、サーバーサイドで弾き `403 Forbidden` を返すこと。

## 6. データ要件
レビューの本体情報を保持するため、以下のデータ構造（テーブル定義想定）を持つ。

| 項目名 | データ型 | 制約 | 備考 |
| :--- | :--- | :--- | :--- |
| `review_id` | INT | PK, Auto Increment | レビュー一意識別子 |
| `user_id` | INT | FK, 必須 | 投稿した会員ID |
| `product_id` | INT | FK, 必須 | 対象の商品ID |
| `rating` | INT | 必須 | 評価（1〜5） |
| `title` | VARCHAR(50) | 任意 | レビュータイトル |
| `body` | TEXT | 必須 | レビュー本文 |
| `status` | VARCHAR(20)| 必須 | 公開状態（例: `published`, `hidden`）デフォルトは `published` |
| `created_at` | DATETIME | 必須 | 作成日時 |
| `updated_at` | DATETIME | 必須 | 更新日時 |

※ `user_id` と `product_id` の組み合わせでユニーク制約（複合ユニーク）を設け、1人1件の仕様をDBレベルで担保する。

## 7. 非機能要件 (追加要件)
* **パフォーマンス:** 商品詳細画面の表示速度を低下させないため、評価の平均値とレビュー件数は、可能であれば非同期で読み込むか、集計テーブル（商品テーブルへのキャッシュ等）を用いて高速に取得できるようにする。
* **セキュリティ:** XSS（クロスサイトスクリプティング）対策のため、レビュー本文およびタイトルの出力時は適切なサニタイズ処理を行う。
