# 商品検索機能強化 - 要件定義書

> **ステータス**: ✅ 要件確定
> **版数**: 1.0

---

## 1. 目的

商品検索のヒット率向上と離脱率低下を目的として、商品検索機能を強化する。

---

## 2. 対象範囲

- ヘッダの検索ボックスからの検索機能と検索結果の一覧画面が対象

---

## 3. 現行仕様サマリー

| 項目 | 現行の動作 |
|---|---|
| 検索対象 | 商品名と商品コードのみ |
| 検索方式 | 商品名・商品コードともに部分一致で検索する |
| 大文字小文字 | 英字の大文字・小文字は区別しない |
| 全角半角 | 全角・半角を区別する（正規化なし） |
| キーワード処理 | 入力文字列をそのまま1つのキーワードとして検索する |
| 絞込条件 | 在庫あり、価格帯、カラー、ソート順 |
| テイスト絞込み | 検索結果画面では利用不可（カテゴリ一覧のみ対応） |
| キーワード最大文字数 | 制限なし |
| プレースホルダー | 「商品名・商品コード」 |

---

## 4. 機能要件

### 4.1 商品コード検索

| # | 要件 | 現行との差異 |
|---|---|---|
| FR-001 | 商品コード検索条件は「完全一致」または「前方一致」のみを対象とする。中間一致では商品コードの一部の数字が意図せず一致してしまう場合があるため。 | **変更あり** — 現行は部分一致（中間一致含む） |
| FR-002 | 商品コードにヒットした場合、ヒットしたバリアントが属する商品単位で表示する（同一商品で複数バリアントがヒットしても1件として表示） | 変更なし（現行踏襲） |
| FR-003 | 商品コード検索とテキスト検索の両方にヒットした場合は、OR条件でまとめて表示する | 変更なし（現行踏襲） |

### 4.2 テキスト検索（商品名・バリエーション名・説明文）

| # | 要件 | 現行との差異 |
|---|---|---|
| FR-010 | 商品名は部分一致検索をサポートする | 変更なし |
| FR-011 | シリーズバリエーション名は部分一致検索をサポートする。バリエーション名を持たない商品はバリエーション名での検索対象外とする（商品名や説明文など他の条件でヒットする場合は表示される） | **新規追加** — 現行は検索対象外 |
| FR-012 | 説明文は部分一致検索をサポートする | **新規追加** — 現行は検索対象外 |

### 4.3 表記ゆれ対応

| # | 要件 | 現行との差異 |
|---|---|---|
| FR-020 | 英字については大文字小文字を区別せず検索できること | 変更なし |
| FR-021 | 数字については全角半角を区別せずに検索できること（例:「１２３」と「123」を同一視） | **新規追加** — 現行は区別する |
| FR-022 | 英字については全角半角を区別せずに検索できること（例:「ＡＢＣ」と「ABC」を同一視） | **新規追加** — 現行は区別する |
| FR-023 | カタカナについては全角半角を区別せずに検索できること（例:「ﾃﾞｽｸ」と「デスク」を同一視） | **新規追加** — 現行は区別する |
| FR-024 | 表記ゆれの正規化はアプリ側（Java）で実装する。SQL側でもカラム値を正規化して比較する（DB上のデータが全角のままでもヒットさせるため） | **新規追加** |

### 4.4 検索結果の絞込条件

| # | 要件 | 現行との差異 |
|---|---|---|
| FR-030 | 検索結果画面の絞込条件に「テイスト」を追加する | **新規追加** — 現行はカテゴリ一覧のみ対応 |
| FR-031 | テイストは「デスクのテイスト」「チェアのテイスト」「収納家具のテイスト」の3グループに分けて表示する。各グループはアコーディオン（折りたたみ）形式とする | **新規追加** |
| FR-032 | カテゴリ間・カテゴリ内ともにOR結合で絞り込む（例: デスクの「ナチュラル」とチェアの「モダン」を選択した場合、いずれかに該当する商品を表示） | **新規追加** |
| FR-033 | テイスト絞込みを選択していないときは全商品を表示する。選択したときはテイスト属性がNULLの商品は非表示とする | **新規追加** |
| FR-034 | テイスト以外の絞込条件（在庫あり・価格帯・カラー・ソート）は現状踏襲とする | 変更なし |

### 4.5 キーワード入力の扱い

| # | 要件 | 現行との差異 |
|---|---|---|
| FR-040 | スペース区切りで複数語を入力した場合も、1つのキーワードとしてそのまま検索する（現行踏襲） | 変更なし |
| FR-041 | キーワードの最大入力文字数は100文字とする | **新規追加** — 現行は制限なし |
| FR-042 | 空欄（未入力）で検索した場合は全件を表示する（現行踏襲） | 変更なし |
| FR-043 | 特殊文字（`%` `_` 等）が入力された場合はエスケープして検索する（現行踏襲） | 変更なし |

### 4.6 検索結果が0件の場合の表示

| # | 要件 | 現行との差異 |
|---|---|---|
| FR-045 | 検索結果が0件の場合は「該当する商品は見つかりませんでした。」のメッセージを表示する（現行踏襲） | 変更なし |

### 4.7 検索ボックスのプレースホルダー

| # | 要件 | 現行との差異 |
|---|---|---|
| FR-046 | ヘッダ検索ボックスのプレースホルダー文言を「商品名・商品コード・キーワード」に変更する | **変更あり** — 現行は「商品名・商品コード」 |

### 4.8 現行踏襲

上記以外については現状の商品検索の機能を踏襲する。

| # | 要件 | 備考 |
|---|---|---|
| FR-050 | 検索結果の表示単位は商品単位とする | |
| FR-051 | ページネーション（15件/ページ）は変更しない | |
| FR-052 | ソート順（おすすめ順/価格昇順・降順/新着順）は変更しない | |
| FR-053 | 表示件数の切替（15/30/60件）は変更しない | |
| FR-054 | 販売期間外の商品は検索対象としない（現行踏襲） | |

---

## 5. 非機能要件

| # | 区分 | 要件 | 現行との差異 |
|---|---|---|---|
| NFR-001 | 性能 | 検索対象の商品数は最大1,000件程度を想定する | **新規追加** — 現行は制約なし |
| NFR-002 | 性能 | 一覧の初回表示は95%の場合で2秒以内を目標とする。表示件数60件の場合も含む。現状アーキテクチャへの追加実装のみで達成する（インデックス追加・キャッシュ導入は行わない） | **新規追加** — 現行は目標値なし |

---

## 6. 対象外

- 管理画面における商品検索機能（本システム外）
- ヘッダ検索ボックス以外からの検索（カテゴリ一覧のフィルタ等）
- 検索キーワードのサジェスト・オートコンプリート機能
- 検索結果0件時の代替キーワード提案機能
