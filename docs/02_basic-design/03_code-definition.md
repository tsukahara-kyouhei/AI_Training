# コード定義書

## 1. 商品

### 1.1 商品カテゴリ（category_id）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `desk` | デスク | デスク類。デスク固有属性テーブルあり |
| `chair` | チェア | チェア類。チェア固有属性テーブルあり |
| `storage` | 収納家具 | 収納家具類。収納固有属性テーブルあり |

### 1.2 商品ソート順（ProductSort）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `recommended` | おすすめ順 | デフォルトのソート順（推奨商品優先） |
| `newest` | 新着順 | 販売開始日の新しい順 |
| `price_asc` | 価格が安い順 | 単価の昇順 |
| `price_desc` | 価格が高い順 | 単価の降順 |

### 1.3 カラースウォッチ種別（swatch_type）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `solid` | ソリッド | 単色のカラーチップ |
| `transparent_pattern` | 透過パターン | パターン・テクスチャのカラーチップ |

## 2. 会員

### 2.1 会員種別（personal_or_corporate）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `personal` | 個人 | 個人会員。会社名・部署名は任意 |
| `corporate` | 法人 | 法人会員。会社名は必須 |

### 2.2 会員状態（member_status）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `active` | 有効 | 通常通り利用可能な会員 |
| `withdrawn` | 退会済み | 退会処理済み。ログイン不可 |

### 2.3 性別（gender）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `male` | 男性 | - |
| `female` | 女性 | - |
| `no_answer` | 回答しない | - |

---

## 3. 注文

### 3.1 注文ステータス（order_status）

| コード値 | 表示名 | 説明 | 遷移元 |
|---|---|---|---|
| `received` | 受付済み | 注文直後の初期状態 | （初期値） |
| `awaiting_payment` | 入金待ち | 銀行振込・コンビニ決済で入金待ち | received |
| `processing` | 処理中 | 入金確認済み・商品準備中 | received / awaiting_payment |
| `completed` | 完了 | 配送完了 | processing |
| `cancelled` | キャンセル | 注文キャンセル済み | received / awaiting_payment / processing |

### 3.2 顧客種別（customer_type）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `guest` | ゲスト | 会員登録なしで注文した顧客。`member_id` は NULL |
| `member` | 会員 | 会員としてログイン済みで注文。`member_id` にIDが設定 |

### 3.3 支払方法（payment_method）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `bank_transfer` | 銀行振込 | 指定口座へ振込。`awaiting_payment` ステータスで開始 |
| `cash_on_delivery` | 代金引換 | 配送時に代金支払。`processing` ステータスで開始 |
| `convenience_store` | コンビニ決済 | コンビニで支払。`payment_instruction` に決済情報を格納 |

### 3.4 配送方法（shipping_method）

| コード値 | 表示名 | 説明 |
|---|---|---|
| `normal` | 通常配送 | 標準配送 |
| `assembly` | 組立・設置込み配送 | 組立・設置サービス付き。追加費用あり |

## 4. お問い合わせ

### 4.1 お問い合わせ種別（inquiry_type）

> ※ DBカラム定義・バリデーションから抽出

| コード値 | 表示名 |
|---|---|
| `product` | 商品について |
| `order` | 注文について |
| `delivery` | 配送について |
| `return` | 返品・交換について |
| `other_before` | その他（注文前） |
| `other_after` | その他（注文後） |

### 4.2 注文状況区分（order_phase）

| コード値 | 表示名 |
|---|---|
| `before_order` | 注文前 |
| `after_order` | 注文後 |

## 5. バリデーション制約

### 5.1 数値制約

| フィールド | 制約 |
|---|---|
| カート数量 | 1〜99 |
| 追加お届け先 | 最大20件/会員 |
| お気に入り | 最大100件/会員 |
| 電話番号・FAX | 数字10〜12桁 |
| 郵便番号 | 数字7桁（ハイフンなし） |
| パスワード | 半角英数字記号 8〜64文字 |

### 5.2 文字列長制約

| フィールド | 最大文字数 |
|---|---|
| 姓・名 | 各50文字 |
| 姓カナ・名カナ | 各50文字 |
| 会社名 | 120文字 |
| 部署名 | 120文字 |
| メールアドレス | 254文字 |
| 都道府県 | 20文字 |
| 市区町村 | 120文字 |
| 番地・ビル名 | 255文字 |
| お問い合わせ内容 | 1000文字 |
| 商品名（問合せ） | 255文字 |
| 商品コード（問合せ） | 32文字 |
| 備考（注文） | 500文字 |
