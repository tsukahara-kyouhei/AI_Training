## 1. 障害概要

注文確定操作（「注文を確定する」ボタン押下）時にシステムエラー画面に遷移する。
注文完了画面に遷移することが期待される動作であり、注文が正常に完了しない状態。
ローカル開発環境の初期構築直後に発生が確認されており、別の担当者の環境では再現しない。

## 3. 事象詳細

「注文を確定する」ボタン押下後、注文完了画面ではなくシステムエラー画面に遷移する。

**再現手順**

1. 会員ユーザー（member01@example.com）でログイン
2. カートに商品を2件（P0001-C01、P0001-C02）追加
3. カートから注文確認画面まで遷移（各入力項目はデフォルトのまま）
4. 「注文を確定する」ボタンを押下
5. **システムエラー画面に遷移**（← 障害発生）

**期待される動作**

「注文を確定する」ボタン押下後、システムエラー画面に遷移せずに注文完了画面に遷移する。
