## 1. 機能概要

- 会員がログインするための画面を提供し、ログイン後に元のページへ戻るための案内を行う。
- すでにログインしている会員には、ログイン画面ではなくマイページを表示する。
- 利用者が希望した場合、以前入力したメールアドレスをログイン画面に表示して入力を補助する。
- セッションの有効期限が切れた場合に、そのことを利用者へ知らせて再度ログインできるようにする。

## 2. 入出力項目

| 項目区分 (入力/出力) | 項目名 | 説明 |
|---|---|---|
| 入力 | URL パラメータ `redirect` | ログイン後の戻り先候補。安全な相対パスに正規化してフォームに設定する。省略可能。 |
| 入力 | URL パラメータ `expired` | セッション切れを示すフラグ。省略時は `false`。 |
| 入力 | HTTP セッションの認証状態 | 現在ログイン中の会員がいるかを確認するために参照する。 |
| 入力 | メールアドレス記憶 Cookie | `office_order_login_email` に保存されたメールアドレス。存在する場合はログインフォームの初期値として利用する。 |
| 入力 | 画面モデル `loginForm` | 既にモデルに設定されている場合は維持する。設定されていない場合は新しいフォームを作成する。 |
| 出力 | 遷移先 | ログイン済みの場合は `/mypage/orders` へリダイレクトし、未ログインの場合は `pages/login` を表示する。 |
| 出力 | 画面モデル `loginForm` | ログイン画面のフォーム。正規化した戻り先と、記憶済みメールアドレスがあればその値を含む。 |
| 出力 | 画面モデル `rememberLoginEmail` | 記憶済みメールアドレスがあるかを示す真偽値。 |
| 出力 | 画面モデル `sessionExpired` | セッション切れの案内を表示するかを示す真偽値。 |
