## 1. 機能概要

- 商品や注文、配送などに関するお問い合わせを送信する機能を提供する。
- ログイン中の会員には、登録済みの連絡先情報をフォームに反映し、入力の手間を減らす。
- 入力内容に不備がある場合は、修正箇所を示して再入力できるようにする。
- 送信を受け付けた場合は受付完了を知らせ、問い合わせ番号を案内する。
- 送信に失敗した場合はエラーを知らせ、フォームから再度操作できるようにする。

## 2. 入出力項目

| 項目区分 (入力/出力) | 項目名 | 説明 |
|---|---|---|
| 入力 | HTTP セッションのログイン会員情報 | ログイン中かどうかの判定と、送信時の会員識別に使用する。未ログインの場合、会員 ID は未設定として扱う。 |
| 入力 | 画面モデル `contactForm` | 既に画面モデルに設定されている場合はそのフォームを利用する。未設定の場合は新しいフォームを作成し、ログイン会員の連絡先情報があれば初期値に反映する。 |
| 入力 | お問い合わせフォーム `companyName`、`departmentName` | 会社名・部署名。任意入力。 |
| 入力 | お問い合わせフォーム `lastName`、`firstName` | お問い合わせ者の姓・名。必須。 |
| 入力 | お問い合わせフォーム `email`、`phone` | 連絡先メールアドレス（必須）と電話番号（任意）。 |
| 入力 | お問い合わせフォーム `inquiryType`、`orderPhase` | お問い合わせの種類と注文前／注文後の区分。必須。 |
| 入力 | お問い合わせフォーム `productName`、`productCode` | 対象商品名と商品コード。任意入力。 |
| 入力 | お問い合わせフォーム `message` | お問い合わせ本文。必須、最大 1000 文字。 |
| 出力 | 遷移先 `pages/contact` | お問い合わせ画面。入力エラー時や送信失敗時も同じ画面を表示する。 |
| 出力 | 画面モデル `contactForm` | 入力フォーム。会員の初期連絡先情報、または送信された入力値を表示する。 |
| 出力 | 入力検証結果 | 入力内容に不備がある場合、項目ごとのエラーメッセージをフォームに表示する。 |
| 出力 | 画面モデル `contactError` | お問い合わせの保存に失敗した場合に画面へ表示するエラーメッセージ。 |
| 出力 | 遷移先 `redirect:/contact` | 送信受け付け後のお問い合わせ画面へのリダイレクト先。 |
| 出力 | フラッシュ属性 `contactSuccessMessage` | お問い合わせを受け付けたことを知らせるメッセージ。 |
| 出力 | フラッシュ属性 `contactInquiryNumber` | 受付 ID を `INQ` と 8 桁の数字で整形した問い合わせ番号。 |
