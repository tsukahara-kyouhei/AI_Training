## 1. 機能概要

- 商品ごとのレビュー一覧と評価の集計を表示し、購入者の感想を確認できる。
- 商品を購入した会員がレビューを投稿できるようにし、投稿済みの場合は内容を編集できる。
- ログイン状態や購入・投稿状況に応じて、レビュー投稿や編集の利用可否を案内する。

## 2. 入出力項目

| 項目区分 (入力/出力) | 項目名 | 説明 |
|---|---|---|
| 入力 | URL パス変数 `productId` | レビュー一覧・投稿・編集の対象商品 ID。 |
| 入力 | 認証済み会員情報 `MemberPrincipal` | ログイン中の会員 ID を取得し、購入済み確認とレビュー取得・登録に使用する。レビュー一覧では未ログインの場合も許容される。 |
| 入力 | レビューフォーム `reviewForm` | レビューの対象商品 ID、評価、タイトル、本文。新規投稿または編集内容を受け取る。 |
| 出力 | 遷移先 `review/list` | 商品レビュー一覧画面。 |
| 出力 | 画面モデル `reviewPage` | 商品のレビュー一覧、件数などのページ情報。対象商品 ID を含む。 |
| 出力 | 画面モデル `reviewSummary` | 商品レビューの評価集計情報。 |
| 出力 | 画面モデル `hasPurchased`、`hasReviewed` | ログイン会員が対象商品を購入済みか、レビュー投稿済みかを示す真偽値。 |
| 出力 | 画面モデル `isLoggedIn`、`currentMemberId` | ログイン状態と、ログイン中の場合の会員 ID。未ログイン時の会員 ID は未設定。 |
| 出力 | 遷移先 `review/form` | レビュー投稿・編集フォーム画面。モデル `reviewForm` に新規フォームまたは既存レビューの内容を渡す。 |
| 出力 | リダイレクト先 `/products/{productId}/reviews` | レビュー投稿・編集後、または購入条件を満たさない場合のレビュー一覧画面。 |
| 出力 | リダイレクト先 `/products/{productId}/reviews/edit?memberId={memberId}` | 対象商品にレビュー投稿済みの会員を編集画面へ案内する。 |
| 出力 | エラー応答 | 未購入商品の投稿、または編集対象レビューが存在しない場合に例外を送出し、共通エラー処理へ委譲する。 |
