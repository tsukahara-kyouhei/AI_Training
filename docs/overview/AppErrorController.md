## 1. 機能概要

- エラー発生時に、ブラウザー利用者へ状況に応じた案内とトップページへ戻る手段を提供する。
- ページが見つからない場合やリクエストに問題がある場合に、原因に応じた利用者向けメッセージを表示する。
- システムエラーの場合に、時間をおいて再試行する案内を行い、問い合わせ時に役立つ受付番号とアクセス先を提示する。
- JSON 応答を求める API クライアントには、HTTP ステータスとエラーコード、メッセージ、受付番号、発生したアクセス先を含むエラー情報を返す。

## 2. 入出力項目

| 項目区分 (入力/出力) | 項目名 | 説明 |
|---|---|---|
| 入力 | エラー発生リクエスト | `/error`（設定により変更可能）に転送されたリクエスト。 |
| 入力 | HTTP エラー状態コード | Servlet のエラー属性から取得する状態コード。未設定または解決できない場合は 500 として扱う。 |
| 入力 | Accept ヘッダー | `application/json` を含む場合、JSON 形式のエラー応答を要求するものとして扱う。 |
| 入力 | リクエスト ID 属性 | エラー画面や JSON 応答に含める受付番号。属性がない場合は空文字になる。 |
| 入力 | エラー発生元 URI 属性 | エラーの発生元として画面または JSON 応答に表示するパス。属性がない場合は現在のリクエスト URI を使う。 |
| 出力 | HTTP ステータス | 見つからない場合は 404、その他のクライアントエラーは該当する 4xx、その他は 500 を返す。 |
| 出力 | 遷移先画面 | HTML 応答では 404 とその他の 4xx に `error/error`、システムエラーに `error/500` を表示する。 |
| 出力 | 画面モデル `statusCode` | エラー画面に表示する HTTP ステータスコード。 |
| 出力 | 画面モデル `errorTitle` | エラー種別に応じた画面タイトル。 |
| 出力 | 画面モデル `errorMessage` | 利用者向けの説明・案内メッセージ。 |
| 出力 | 画面モデル `requestId` | 問い合わせ時に利用できる受付番号。 |
| 出力 | 画面モデル `errorPath` | エラーが発生したアクセス先。 |
| 出力 | JSON `status` | HTTP ステータスコード。 |
| 出力 | JSON `code` | エラー分類コード（`NOT_FOUND`、`REQUEST_ERROR`、`SERVER_ERROR`）。 |
| 出力 | JSON `message` | タイトルと利用者向け説明を結合したメッセージ。 |
| 出力 | JSON `requestId` | リクエスト ID 属性から取得した受付番号。 |
| 出力 | JSON `path` | エラー発生元の URI。 |
