# 用語集

## 1. 業務用語

### 1.1 ユーザー・会員

| 用語 | 英語表記 | 説明 |
|---|---|---|
| ゲストユーザー | Guest User | 会員登録をせずにサイトを利用するユーザー。商品閲覧・カート利用・注文が可能 |
| 会員 | Member | 会員登録済みのユーザー。マイページ機能が利用可能 |
| 個人 | Personal | 会員種別の一つ。個人として登録 |
| 法人 | Corporate | 会員種別の一つ。法人として登録。会社名・部署名の入力が必要 |
| マイページ | My Page | 会員専用ページ。プロフィール編集、住所管理、注文履歴、お気に入り等を提供 |
| 退会 | Withdrawal | 会員がアカウントを無効化すること。論理削除（ソフトデリート）で処理 |

### 1.2 商品

| 用語 | 英語表記 | 説明 |
|---|---|---|
| 商品 | Product | 販売対象のオフィス家具 |
| 商品カテゴリ | Product Category | 商品の大分類。デスク（desk）・チェア（chair）・収納（storage）の3種 |
| バリアント | Product Variant | 同一商品のカラー別バリエーション。色ごとに価格・在庫を管理 |
| カラー | Color | 商品バリアントの色。カラーコード（HEX）とスウォッチ種別を持つ |
| テイスト | Taste | 商品の雰囲気・デザイン傾向を表す分類（ナチュラル、モダン等） |
| 天板形状 | Desk Top Shape | デスクの天板の形状（長方形、L字型等） |
| 組立オプション | Assembly Option | 商品に組立サービスを付けるかどうかの選択 |
| 販売期間 | Sale Period | 商品の販売開始日〜終了日 |
| 新着商品 | New Arrivals | 新しく追加された商品の一覧 |
| 売れ筋ランキング | Popular Ranking | 過去1か月の販売実績に基づくトップ10商品 |
| おすすめ関連商品 | Recommended Related Products | 類似スコアに基づく関連商品（商品あたり上位4件） |
| シリーズ | Product Series | 同一シリーズに属する商品のリンク |

### 1.3 カート・注文

| 用語 | 英語表記 | 説明 |
|---|---|---|
| カート | Shopping Cart | 購入予定商品の一時保存領域。ゲストはCookie、会員はDB管理 |
| カートライン | Cart Line | カート内の1商品行（バリアント＋数量） |
| チェックアウト | Checkout | 購入手続き。4ステップ（支払方法選択→入力→確認→完了） |
| 注文 | Order | 確定した購入情報 |
| 注文番号 | Order Number | `YYYYMMDD` + 連番の形式で採番される一意な番号 |
| 注文明細 | Order Item | 注文内の1商品行 |
| 注文ステータス | Order Status | 注文の処理状態。received → awaiting_payment → processing → completed / cancelled |
| 支払方法 | Payment Method | 決済手段の選択肢 |
| 配送先 | Delivery Address | 商品の届け先住所 |
| お届け先階数 | Delivery Floor | 配送先の階数（大型家具の搬入に必要） |
| エレベーター有無 | Has Elevator | 配送先にエレベーターがあるかどうか |
| 追加お届け先 | Additional Address | 会員が登録できる配送先住所（最大20件） |
| 再購入 | Reorder | 過去の注文から商品をカートに再追加する機能 |

### 1.4 コンテンツ・その他

| 用語 | 英語表記 | 説明 |
|---|---|---|
| お知らせ | Announcement | サイト上に表示するニュース・更新情報。公開期間で管理 |
| お問い合わせ | Contact / Inquiry | ユーザーからの問い合わせ。種類・注文前後の分類あり |
| お気に入り | Favorite | 会員が商品をブックマークする機能（最大100件） |
| 特定商取引法 | Tokusho | 特定商取引法に基づく表記ページ |
| メールマガジン | Newsletter | メール配信の受信可否設定 |
| パンくずリスト | Breadcrumb | 画面上部に表示される階層ナビゲーション |

## 2. 技術用語

### 2.1 アーキテクチャ

| 用語 | 説明 |
|---|---|
| Controller | HTTPリクエストを受け取り、Serviceを呼び出し、Viewに渡すレイヤー |
| Service | ビジネスロジックを実装するレイヤー |
| Repository | データアクセスのインターフェースを定義するレイヤー |
| Mapper | MyBatisのSQLマッパーインターフェース。XMLで定義されたSQLを実行 |
| Mapper Row | MyBatisの結果セットから1行分のデータをマッピングする中間オブジェクト |
| Model | 画面表示用のビューモデルやフォームオブジェクト |
| Fragment | Thymeleafのテンプレート部品。ヘッダー・フッター等の共通コンポーネント |

### 2.2 認証・セキュリティ

| 用語 | 説明 |
|---|---|
| BCrypt | パスワードのハッシュ化アルゴリズム |
| CSRF | クロスサイトリクエストフォージェリ。Spring Securityの標準機能で防御 |
| セッション | HTTPセッション。60分でタイムアウト |
| MDC | Mapped Diagnostic Context。ログにリクエストIDやユーザー情報を付与する仕組み |

### 2.3 バッチ

| 用語 | 説明 |
|---|---|
| Job | Spring Batchのジョブ。1つのバッチ処理単位 |
| Step | ジョブ内の1処理ステップ |
| Execution | ジョブの実行インスタンス。実行ごとに一意のIDが付与される |
| Cron | 定時実行のスケジュール式。本システムでは毎時0分 |

### 2.4 その他

| 用語 | 説明 |
|---|---|
| Mailpit | 開発用のメールサーバーモック。送信メールをWeb UIで確認可能 |
| DbGate | Web UIベースのデータベース管理ツール |
| Thymeleaf | サーバーサイドHTMLテンプレートエンジン |
| MyBatis | SQLマッパーフレームワーク。XMLでSQLを定義しJavaインターフェースにマッピング |
| Maven Wrapper | プロジェクトに同梱されたMavenのラッパー（`mvnw` / `mvnw.cmd`） |
