# 画面一覧

以下は本プロジェクトの主要画面一覧です。画面名、主な機能、URL を示します。

| 画面名                       | 主な機能                                             |                       URL | 備考                                         |
| ---------------------------- | ---------------------------------------------------- | ------------------------: | -------------------------------------------- |
| ホーム                       | トップページ、注目商品やバナー表示                   |                         / |                                              |
| 商品検索（絞り込み）         | キーワード検索、カテゴリ/テイスト/ソート、ページング |          /products/search | 新検索仕様対応（キーワード正規化・トークン） |
| 商品詳細                     | 商品情報表示、バリアント選択、カート追加             |   /products/{productCode} |                                              |
| カート                       | カート内一覧、数量変更、削除、購入手続きへ進む       |                     /cart |                                              |
| 注文入力                     | 配送先・支払方法選択、利用規約同意など               |           /checkout/input | 会員はデフォルト情報を自動入力               |
| 注文確認                     | 注文内容の最終確認（合計金額、配送・支払）           |         /checkout/confirm | 確定ボタンで注文確定処理を実行               |
| 注文完了                     | 注文完了メッセージ、注文番号表示                     |        /checkout/complete | メール送信（確認メール）をトリガー           |
| 注文履歴                     | 会員の過去注文一覧                                   |            /mypage/orders | 要ログイン                                   |
| 注文詳細                     | 注文の詳細情報（明細、配送状況）                     |  /mypage/orders/{orderId} | 要ログイン                                   |
| ログイン                     | 会員ログイン                                         |                    /login | SNS 連携なし（現状）                         |
| 会員登録                     | 新規会員登録フォーム                                 |          /member/register | 確認・完了画面がある                         |
| 会員登録確認                 | 入力内容確認                                         |  /member/register/confirm |                                              |
| 会員登録完了                 | 登録完了メッセージ                                   | /member/register/complete | メール送信あり                               |
| お問い合わせ                 | 問い合わせフォーム送信                               |                  /contact | 送信後確認画面あり                           |
| お知らせ一覧                 | アナウンス一覧表示                                   |            /announcements |                                              |
| 法人案内 / 会社情報          | 会社概要、利用規約、プライバシー                     |         /about, /legal/\* | 複数の法務ページあり                         |
| 利用ガイド                   | サイト利用ガイド                                     |                    /guide |                                              |
| カート（モバイル用モーダル） | モバイル向けフィルタ／カート表示                     |            （モーダル内） | テンプレートで別UIを提供                     |

> 注: 実際の URL パスはルーティング設定と Thymeleaf テンプレートに依存します。必要ならばコントローラの `@RequestMapping` を参照して厳密に列挙します。
