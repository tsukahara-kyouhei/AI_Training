# 画面一覧

> 最終更新: 2026-04-18 （★CUSTOM-001 お薦め機能対応）

## 凡例

| 認証要否 | 説明 |
|----------|------|
| 不要 | 未ログインユーザーも閲覧可能 |
| **要ログイン** | `ROLE_MEMBER` が必要。未認証の場合は `/login?redirect=…` へリダイレクト |

## 2. 商品カタログ

| # | 画面名 | URL | HTTP | 主な機能 | 認証 |
|---|--------|-----|------|----------|------|
| 2-1 | 新着商品一覧 | `/products/new-arrivals` | GET | 新着商品の一覧表示。在庫・価格帯・カラー・ソートで絞り込み | 不要 |
| 2-2 | キーワード検索結果 | `/products/search?q=…` | GET | キーワード・テイスト・在庫・価格帯・カラー・ソートで絞り込み（★FEAT-001）| 不要 |
| 2-3 | デスクカテゴリ一覧 | `/categories/desks` | GET | デスク商品一覧。天板形状・幅・奥行・高さ・テイスト等で絞り込み | 不要 |
| 2-4 | チェアカテゴリ一覧 | `/categories/chairs` | GET | チェア商品一覧。機能・素材・テイスト等で絞り込み | 不要 |
| 2-5 | 収納家具カテゴリ一覧 | `/categories/storages` | GET | 収納家具一覧。用途・テイスト等で絞り込み | 不要 |
| 2-6 | 商品詳細 | `/products/{productId}` | GET | 商品画像・スペック・バリアント選択・カート追加・お気に入り登録。ページ下部に「この商品と合わせてよく見られています」関連商品セクションを追加（★CUSTOM-001 フェーズ1・最大4件） | 不要 |
| 2-7 | お気に入り登録（API） | `/products/{productId}/favorite` | POST | お気に入りのトグル登録 → 元ページへリダイレクト（未ログインはログイン画面へ誘導） | 不要 |
| 2-8 | 最近見た商品（API） | `/products/recently-viewed` | GET | 最近閲覧した商品リストを JSON で返却 | 不要 |

**共通クエリパラメータ（絞り込み・ソート）**

| パラメータ | 用途 |
|-----------|------|
| `inStockOnly` | 在庫ありのみ |
| `priceBand[]` | 価格帯（複数選択） |
| `color[]` | カラー（複数選択） |
| `sort` | ソート順 |
| `page` / `size` | ページネーション |
| `q` | キーワード（検索結果のみ） |
| `taste[]` | テイスト（複数選択）★FEAT-001 |

## 3. 認証・会員登録

| # | 画面名 | URL | HTTP | 主な機能 | 認証 |
|---|--------|-----|------|----------|------|
| 3-1 | ログイン | `/login` | GET | メール・パスワードによるログインフォーム | 不要 |

| 3-3b | 会員登録（バリデーション） | `/members/register/confirm` | POST | バリデーション → 確認画面へ or 入力画面へ戻る | 不要 |
| 3-4 | 会員登録確認 | — | — | 入力内容を確認（`/members/register/confirm` POST のビューとして表示） | 不要 |
| 3-4b | 会員登録（確定） | `/members/register` | POST | セッション内容を DB 登録 → 完了画面へリダイレクト | 不要 |
| 3-5 | 会員登録完了 | `/members/register/complete` | GET | 登録完了メッセージ表示（フラッシュ属性がなければ 404） | 不要 |

## 4. カート・購入フロー

| # | 画面名 | URL | HTTP | 主な機能 | 認証 |
|---|--------|-----|------|----------|------|
| 4-1 | カート | `/cart` | GET | カート内商品一覧・数量変更・削除・小計表示。ページ下部に「こちらもいかがですか？」クロスセルセクションを追加（★CUSTOM-001 フェーズ1・最近見た商品Cookie起点・最大4件） | 不要 |
| 4-1b | カート追加 | `/cart/items` | POST | 商品バリアントをカートへ追加 → 元ページへリダイレクト | 不要 |
| 4-1c | カート数量更新 | `/cart/items/{productVariantId}/update` | POST | 数量変更 → `/cart` へリダイレクト | 不要 |
| 4-1d | カートアイテム削除 | `/cart/items/{productVariantId}/delete` | POST | 1 アイテム削除 → `/cart` へリダイレクト | 不要 |
| 4-1e | カートクリア | `/cart/clear` | POST | 全アイテム削除 → `/cart` へリダイレクト | 不要 |
| 4-2 | 購入方法選択 | `/checkout/method` | GET | ゲスト購入 or 会員ログイン購入の選択（カートが空なら `/cart` へ） | 不要 |
| 4-3 | 注文情報入力 | `/checkout/input` | GET | 配送先・氏名・メール・電話番号・支払方法の入力（会員ログイン時は初期値補完） | 不要 |
| 4-3b | 注文情報入力（送信） | `/checkout/input` | POST | バリデーション → 確認画面へ or 入力画面へ戻る | 不要 |
| 4-4 | 注文確認 | `/checkout/confirm` | GET | 注文内容・配送先・金額の最終確認（ワンタイムトークン生成） | 不要 |
| 4-4b | 注文確定 | `/checkout/confirm` | POST | ワンタイムトークン検証 → 注文 DB 登録 → 完了画面リダイレクト | 不要 |
| 4-5 | 注文完了 | `/checkout/complete/{orderNumber}` | GET | 注文番号・完了メッセージ表示（直アクセスは入力画面へリダイレクト） | 不要 |
