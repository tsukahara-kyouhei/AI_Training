## 凡例

| 記号 | 意味 |
|:---:|------|
| **C** | CREATE（INSERT） |
| **R** | READ（SELECT） |
| **U** | UPDATE |
| **D** | DELETE |
| **C/U** | UPSERT（INSERT … ON CONFLICT DO UPDATE） |
| **−** | アクセスなし |
