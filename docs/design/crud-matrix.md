# CRUDマトリクス

本ドキュメントは、本プロジェクトで実装・利用されている主要データエンティティに対する CRUD 操作を、画面・業務観点で整理したものです。

| エンティティ | Create | Read | Update | Delete | 備考 |
| --- | --- | --- | --- | --- | --- |
| 会員 | ○ | ○ | ○ | △ | 会員登録、プロフィール更新、退会（論理削除） |
| 追加お届け先 | ○ | ○ | ○ | ○ | マイページから登録・編集・削除 |
| お気に入り | ○ | ○ | × | ○ | 商品詳細から追加、マイページから削除 |
| 商品 | × | ○ | × | × | 商品一覧・詳細表示は実装済み。管理画面の登録更新削除は未実装 |
| 商品バリアント | × | ○ | × | × | 在庫・価格情報の表示に利用 |
| 注文 | ○ | ○ | △ | △ | 注文確定で作成、履歴/詳細参照。ステータス更新・キャンセルは限定的 |
| 注文明細 | ○ | ○ | × | × | 注文時に自動生成 |
| 注文ステータス履歴 | ○ | ○ | × | × | システムによる状態変更履歴の記録 |
| お知らせ | × | ○ | × | × | 一覧表示のみ実装 |
| 問い合わせ | ○ | × | × | × | 入力フォームから送信 |

## 補足

- ○: 実装・利用あり
- △: 一部対応または限定的
- ×: 未実装または該当なし

## 主な画面との対応

| 画面 | 主なCRUD対象 |
| --- | --- |
| 会員登録 | 会員 Create |
| ログイン | 会員 Read |
| マイページプロフィール | 会員 Update |
| マイページ配送先 | 追加お届け先 CRUD |
| マイページお気に入り | お気に入り CRUD |
| 商品一覧・詳細 | 商品 Read |
| カート・購入フロー | 注文 Create、注文明細 Create |
| 注文履歴 | 注文 Read |
| お知らせ一覧 | お知らせ Read |
| お問い合わせ | 問い合わせ Create |
