# CRUD図

## 凡例

| 記号 | 操作 | SQL |
|:---:|------|-----|
| **C** | 作成 | INSERT |
| **R** | 参照 | SELECT |
| **U** | 更新 | UPDATE |
| **D** | 削除 | DELETE |
| `-`  | 操作なし | — |

## 補足

- **カートのDB操作なし** — カート内容は Cookie ベースで管理。カート表示時は商品スナップショット取得（SELECT）と税率取得（SELECT）のみ実施。
- **お気に入り操作の経路** — 追加・解除は `CatalogController` が担当し、`member_favorites` に対して存在確認（R）→ INSERT（C）または DELETE（D）を行う。マイページ一覧（機能 16）は参照のみ。
- **order_number_counters の CU** — 注文確定時に `INSERT … ON CONFLICT DO UPDATE` による UPSERT（採番）を実施するため C・U 両方を記載。
- **popular_product_rankings / recommended_related_products の CD** — バッチ処理で対象日付のレコードを DELETE 後に再 INSERT（洗替）するため C・D 両方を記載。
- **Spring Batch メタデータテーブル** — `BATCH_JOB_INSTANCE` 等の Spring Batch 管理テーブル群はフレームワークが自動管理するため本図の対象外。
