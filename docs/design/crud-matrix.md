## 補足

### カート（F04）について
カート情報はサーバーサイドのDB ではなく Cookie（クライアントサイド）で管理するため、対象となるデータベーステーブルはありません。
カート画面でDBにアクセスするのは、カート内商品の最新価格・在庫・税率を取得する参照処理のみです。

### 注文確定（F05）について
- 注文番号カウンタ（`order_number_counters`）は日付ごとのシーケンス採番のため、INSERT または UPDATE の UPSERT（`CU`）となります。
- 会員でのチェックアウト時は会員情報を参照して入力フォームを自動補完します。

### お気に入り（F10）について
- 商品詳細ページ（F03）でもお気に入り状態の参照（R）を行います。
- マイページのお気に入り一覧画面では C/D 操作は発生しません（F10 で実施）。

### バッチ処理（F15, F16）について
- F15（ランキング集計）: 過去1ヶ月分の注文データから売れ筋商品を集計し、当日分のランキングを削除→再登録（`CD`）します。
- F16（レコメンド集計）: 共起分析から関連商品を算出し、当日分を削除→再登録（`CD`）します。
- いずれもSpring Batchで実装されており、ジョブ実行履歴は`spring_batch_metadata`系テーブル（フレームワーク管理）に記録されます。

### マスタテーブルについて
`desk_top_shapes` / `desk_tastes` / `chair_functions` / `chair_materials` / `chair_tastes` / `storage_usages` / `storage_tastes` / `colors` は読み取り専用マスタとして利用されます。
本システムの機能にマスタの更新機能はなく、データはSQLシードファイルにより初期投入されます。
