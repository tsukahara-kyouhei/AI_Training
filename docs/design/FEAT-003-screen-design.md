# FEAT-003: 画面設計書

## 1. 商品詳細ページ（レビューセクション追加）

### 1.1 配置

既存の商品詳細ページ (`product-detail.html`) の関連商品セクションの直前にレビューセクションを挿入する。

```
[既存] 商品情報（画像・価格・カラー選択・カート・お気に入り）
[既存] シリーズリンク
 ──────────────────────────
[新規] レビューセクション        ← ここに追加
 ──────────────────────────
[既存] 関連商品
```

### 1.2 レビューサマリー表示

```
┌─────────────────────────────────────────────┐
│ カスタマーレビュー                              │
│ ★★★★☆ 4.2（12件のレビュー）                   │
└─────────────────────────────────────────────┘
```

- 平均評価を星アイコンで表示（1〜5、0.5 刻みの塗りつぶし表現）。
- 件数を「(N件のレビュー)」形式で併記。
- レビューが 0 件の場合は「まだレビューはありません」と表示。

### 1.3 投稿/編集ボタン表示条件

| 状態 | 表示 |
|------|------|
| 未ログイン | 「レビューを書く」ボタン表示 → 押下でログイン画面へ遷移 |
| ログイン済み・購入履歴なし | ボタン非表示 |
| ログイン済み・購入履歴あり・未投稿 | 「レビューを書く」ボタン表示 |
| ログイン済み・購入履歴あり・投稿済み | 「レビューを編集する」ボタン表示 |
| 投稿済み・更新ブロック中 | 「レビューを編集する」ボタン非表示（ブロック中は操作不可） |

### 1.4 レビュー一覧

```
┌─────────────────────────────────────────────┐
│ ★★★★★                        2026-04-10    │
│ とても使いやすいデスクです                       │
│                                             │
│ 組み立ても簡単で、天板の質感も良いです。          │
│ 在宅勤務用に購入しましたが大満足です。            │
├─────────────────────────────────────────────┤
│ ★★★☆☆                        2026-04-05    │
│ 普通です                                     │
│                                             │
│ 特に問題はありませんが、価格相応かなと思います。    │
├─────────────────────────────────────────────┤
│          [ もっと見る ]                       │
└─────────────────────────────────────────────┘
```

- 各レビューの表示項目: 評価（星）、タイトル（太字）、本文、投稿日時。
- タイトルが未入力の場合はタイトル行を非表示。
- 初期表示は最新 5 件。
- 6 件以上ある場合に「もっと見る」ボタンを表示。
- 「もっと見る」押下で `GET /products/{productId}/reviews?page=N&size=5` を非同期呼び出しし、レビューを追加描画する。
- 追加取得分に次ページがなければ「もっと見る」ボタンを非表示にする。

### 1.5 インライン投稿/編集フォーム

「レビューを書く」または「レビューを編集する」ボタン押下でフォームセクションを展開表示する。

```
┌─────────────────────────────────────────────┐
│ レビューを投稿                                 │
│                                             │
│ 評価 ★ ★ ★ ★ ★  (クリックで選択)             │
│                                             │
│ タイトル（任意）                                │
│ ┌─────────────────────────────────────────┐ │
│ │                                         │ │
│ └─────────────────────────────────────────┘ │
│                                             │
│ 本文                                         │
│ ┌─────────────────────────────────────────┐ │
│ │                                         │ │
│ │                                         │ │
│ │                                         │ │
│ └─────────────────────────────────────────┘ │
│                                   0/1000文字 │
│                                             │
│ ☑ このレビューを公開する                       │
│                                             │
│ [ 投稿する ]  [ キャンセル ]                   │
│                                             │
│ (編集時のみ) [ このレビューを削除する ]           │
└─────────────────────────────────────────────┘
```

- 評価: 星アイコンのクリックで 1〜5 を選択。hidden input に値をセット。
- タイトル: テキスト入力（maxlength=100）。
- 本文: textarea（maxlength=1000）。残り文字数をリアルタイム表示。
- 公開状態: チェックボックス（デフォルト ON）。
- 編集時: 既存値をフォームにプリセット。「削除する」リンクを追加表示。
- 削除確認: JavaScript の confirm ダイアログで確認後に POST 送信。
- バリデーションエラー: 各入力項目の直下にエラーメッセージを赤字表示。
- フォームの action:
  - 新規: `POST /products/{productId}/reviews`
  - 更新: `POST /products/{productId}/reviews/{reviewId}`
  - 削除: `POST /products/{productId}/reviews/{reviewId}/delete`

## 2. 商品一覧ページ（商品カードへの評価表示追加）

### 2.1 商品カードの変更

既存の商品カード (`product-card.html` フラグメント) に平均評価と件数を追加。

```
┌────────────────────┐
│    [商品画像]        │
│                    │
│ 商品名              │
│ ¥12,000（税込）     │
│ ★★★★☆ 4.2 (12)   │  ← 追加行
│ ● ● ●             │
└────────────────────┘
```

- レビューが 0 件の場合は評価行を非表示。
- 平均評価は小数点第 1 位まで表示。
