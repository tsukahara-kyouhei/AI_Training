# FEAT-001: 商品検索機能強化 設計書（テスト仕様）

## 1. 目的

- 本機能強化に対する受け入れ基準とテストケースを定義する。

## 2. 受け入れ基準

- 検索キーワードが商品コード、商品名、シリーズ名、説明文に対して正しく検索される。
- 商品コードは完全一致と前方一致のみ一致対象とする。
- 商品名・シリーズバリエーション名・説明文は部分一致検索を行う。
- 英字は大文字小文字を区別せず検索できる。
- 数字・英字・カタカナの全角半角差異を吸収する。
- 検索結果画面にテイスト絞り込みが追加され、複数選択可能である。
- 検索キーワードとテイスト絞り込みは AND 条件で組み合わせる。
- 0 件時に `該当する商品がありませんでした。` が表示される。
- 既存の絞り込み / ソート / ページング機能は従来通り動作する。

## 3. テストケース

### 3.1 基本検索

- キーワード `product-code` を入力し、商品コードの完全一致結果が返ること。
- キーワード `product` を入力し、商品コードの前方一致結果が返ること。
- キーワードの途中一致（例: 商品コードの中間文字列）では該当しないこと。

### 3.2 テキスト検索

- 商品名の一部キーワードで検索し、該当商品が返ること。
- シリーズバリエーション名の一部キーワードで検索し、該当商品が返ること。
- 説明文の一部キーワードで検索し、該当商品が返ること。

### 3.3 表記ゆれ

- 英字の大文字と小文字で同じ検索結果が返ること。
- 全角数字・半角数字の混在した入力で検索できること。
- 全角英字・半角英字を混在させても検索できること。
- 全角カタカナ・半角カタカナを混在させても検索できること。

### 3.4 複数語 AND 検索

- `キーワード1 キーワード2` のように複数語を入力した場合、両語を含む商品が返ること。
- 全角スペースでも AND 検索として扱われること。

### 3.5 テイスト絞り込み

- テイストを 1 つ選択した場合、そのテイストを持つ商品のみが返ること。
- テイストを複数選択した場合、いずれかのテイストを持つ商品が返ること。
- キーワード検索とテイスト絞り込みを同時に指定すると、両方を満たす結果が返ること。

### 3.6 0 件表示

- 検索条件に合致する商品がない場合、 `該当する商品がありませんでした。` が表示されること。

### 3.7 既存機能との整合性

- 価格帯絞り込み、カラー絞り込み、在庫絞り込み、ソート、ページングが従来通り動作すること。
- 検索結果のリセット後、キーワードのみをクリアせず既存の動作を維持すること。

## 4. 性能検証

- 最大 1000 件想定の検索対象で、検索結果一覧の初回表示が 95% で 2 秒以内に収まるかを確認する。
- 画面描画完了までを含むレスポンスタイムを基準とし、実装後に実測値を取得する。

## 5. テスト実装候補

- 単体テスト
  - `ProductRepository` の検索条件パラメータ生成と `toKeywordLike` 拡張のテスト
  - 正規化ロジックのテスト
- 結合テスト / スライステスト
  - 検索画面からのリクエストに対する結果の検証
- UI テスト
  - 0 件メッセージ表示
  - テイストチェックボックスの選択と条件付与
