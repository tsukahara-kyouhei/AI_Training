# FEAT-003 会員レビュー機能設計

## 1. 概要

本設計では、商品に対するログイン会員からのレビュー投稿・編集、および商品詳細・一覧画面でのレビュー情報（平均評価・件数・一覧）表示処理を定義する。

## 2. 対象範囲

- レビュー情報の保存・更新（`product_review` テーブル）
- ログイン会員の購入履歴チェックロジック
- 1会員1商品1レビューの更新制御
- 商品一覧・詳細画面への平均評価・件数表示
- 商品詳細画面への最新レビュー一覧表示

## 3. 画面からの入力フロー

1. ユーザーが商品詳細画面からレビュー投稿・編集フォームを送信する。
2. Controller で未ログイン判定を行い、未ログイン時はログイン画面へリダイレクトする。
3. Service 層で購入履歴の有無を確認し、未購入の場合はエラーレスポンスを返す。
4. 既に同一商品へのレビューが存在する場合は UPDATE、存在しない場合は INSERT を実行する。
5. 更新後のレビュー集計（平均評価・件数）を再計算し、画面へ反映する。

## 4. 業務ロジック

### 4.1 投稿権限および更新判定

投稿・編集の実行に対して、以下を行う。

- セッションよりログイン会員IDを取得する
- 対象商品の購入履歴（`orders` / `order_items`）の存在を検証する
- 過去のレビュー存在有無を判定し、新規（INSERT）か更新（UPDATE）かを自動分岐する
