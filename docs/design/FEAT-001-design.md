# FEAT-001 設計書

## 1. 目的
ヘッダ検索および検索結果一覧に対して、商品検索精度を向上させるための設計を定義する。

## 2. 設計方針
- 既存の検索画面・検索結果画面の構成を維持しつつ、検索条件の解釈とSQL条件を拡張する。
- 検索ロジックは既存の Controller / Service / Mapper / SQL 層に順次組み込む。
- 既存のカテゴリ一覧の絞り込み仕様と整合するように、検索結果画面の「テイスト」絞り込みも共通化する。
- 既存の検索画面の挙動は維持しつつ、追加条件のみを実装対象とする。

## 3. 対象範囲
- ヘッダ検索ボックスからの検索
- 検索結果一覧画面
- 検索条件に基づく商品絞り込み
- 検索結果一覧における「テイスト」絞り込み

## 4. 構成要素
### 4.1 画面
- ヘッダ検索フォーム
- 検索結果一覧画面

### 4.2 サーバー処理
- 商品検索リクエスト受付
- 検索条件の正規化
- 検索クエリ生成
- 検索結果の整形・画面モデルへの詰め替え

### 4.3 データアクセス
- MyBatis Mapper
- SQL 条件分岐

## 5. 機能設計
### 5.1 検索条件の整理
検索条件は以下のように分類する。

- 商品コード
  - 完全一致
  - 前方一致
  - 中間一致は対象外
- 商品名
  - 部分一致
- シリーズバリエーション名
  - 部分一致
- 説明文
  - 部分一致

### 5.2 文字列検索の扱い
検索時に以下の正規化を行う。

- 英字は大文字小文字を区別しない
- 数字・英字・カタカナは全角半角を区別しない
- 既存の検索入力値は、検索条件生成時に正規化した上で利用する

### 5.3 検索条件の実装方針
- 商品コード検索は、SQL上で「完全一致」または「前方一致」の条件に変換する。
- 商品名・シリーズバリエーション名・説明文は、部分一致条件として扱う。
- 文字列の比較は、DB側またはアプリケーション側で正規化を行い、一貫した検索結果を返す。

## 6. 画面設計
### 6.1 検索結果一覧
- 既存の一覧表示レイアウトは維持する。
- 検索結果画面の絞り込み条件に「テイスト」を追加する。
- 「テイスト」の表示・選択・保持動作は、カテゴリ一覧の既存仕様に合わせる。

### 6.2 検索条件の保持
- 検索フォームから遷移した場合、選択中の絞り込み条件をクエリパラメータとして保持する。
- ソート・ページング・絞り込み条件の切り替え時でも、検索条件が維持されるようにする。

## 7. データ設計
### 7.1 既存データの利用
- 既存の商品テーブル・関連テーブルのカラムを利用する。
- 追加テーブルの作成は行わず、既存データ構造を活用する。

### 7.2 検索条件の受け渡し
- Controller で受け取った検索入力を、Service で検索条件オブジェクトに変換する。
- Mapper へは、検索条件オブジェクトをそのまま渡すか、必要なパラメータに分解して渡す。

## 8. 性能設計
### 8.1 対象件数
- 検索対象の商品数は最大約1000件程度を想定する。

### 8.2 実装方針
- 検索条件はSQLで絞り込むことで、一覧初回表示の応答性を確保する。
- 検索対象件数が多い場合でも、必要最小限の列を取得する。
- 可能な限り、DB側で条件処理を実行し、アプリケーション側の後処理を最小化する。

### 8.3 パフォーマンス目標
- 一覧初回表示は、95%のケースで2秒以内を目標とする。
- 目標達成のため、検索条件の複雑さが増えすぎないように実装する。

## 9. テスト方針
### 9.1 単体テスト
- 検索条件の正規化ロジック
- 商品コード検索条件の生成ロジック
- テキスト検索条件の生成ロジック

### 9.2 統合テスト
- ヘッダ検索から検索結果画面への遷移
- 商品名・説明文・シリーズバリエーション名の検索結果確認
- 大文字小文字・全角半角の扱い確認
- テイスト絞り込みの反映確認

## 10. 実装順序
1. 検索条件オブジェクトおよび正規化処理の追加
2. 商品コード検索条件の分岐実装
3. 商品名・シリーズバリエーション名・説明文の部分一致条件実装
4. 検索結果一覧の「テイスト」絞り込み対応
5. 画面表示・ページング・ソートの整合性確認
6. 性能・受入条件の確認

## 11. 受入基準との対応
- 商品コード検索で完全一致・前方一致が利用できること
- 商品名・シリーズバリエーション名・説明文で部分一致検索が利用できること
- 英字の大小文字および全角半角の差異を吸収できること
- 検索結果画面に「テイスト」絞り込みが表示されること
- 既存の検索画面の基本動作が維持されること
