# FEAT-001 テスト設計

## 1. テスト方針

本機能は、検索ロジック・画面表示・絞り込み条件・0件時表示を対象とするため、単体テスト・統合テスト・受け入れテストを組み合わせて検証する。

## 2. 単体テスト

### 2.1 正規化ロジック

- 前後空白の除去
- 英字の大小文字差異吸収
- 全角/半角の差異吸収

### 2.2 検索条件生成

- 空入力時の挙動
- 商品コード完全一致
- 商品コード前方一致
- 商品名/シリーズ/説明文部分一致
- 中間一致が発生しないこと

## 3. 統合テスト

- ヘッダー検索から検索結果一覧へ遷移すること
- 検索結果が商品カード一覧として表示されること
- テイスト絞り込みが AND 条件で動作すること
- 0件時にメッセージが表示されること
- ページネーションが動作すること

## 4. 受け入れテスト

- 商品コード検索で完全一致/前方一致のみヒットする
- 商品名・シリーズ名・説明文で部分一致検索が動作する
- 英字・数字・カタカナの全角/半角差異が吸収される
- テイスト絞り込みを併用できる
- ヘッダー検索から検索結果が正しく表示される
