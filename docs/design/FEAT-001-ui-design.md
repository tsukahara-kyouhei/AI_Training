# FEAT-001 画面設計

## 1. 対象画面

- ヘッダー検索ボックス
- 検索結果一覧画面
- 検索結果一覧の絞り込みUI

## 2. ヘッダー検索ボックス

### 2.1 画面要件

- ヘッダーの検索入力欄から検索キーワードを送信できること
- 検索実行後は検索結果一覧画面へ遷移すること
- 入力値に余分な空白が含まれていても、トリムして処理すること

### 2.2 UI仕様

- 既存の検索フォームを継続利用する
- name 属性は既存の q を維持する
- 入力欄のプレースホルダは既存の「商品名・商品コード」を維持する
- 空入力時は既存のヘッダー検索挙動に合わせて扱う

## 3. 検索結果一覧画面

### 3.1 表示項目

- 検索キーワード
- ヒット件数
- 商品カード一覧
- 0件時メッセージ
- ページネーション

### 3.2 条件で絞り込む

検索結果一覧画面側に、既存カテゴリ一覧と同じ「テイスト」絞り込み条件を追加する。

- 既存画面で使っている絞り込みUIと同じコンポーネントを再利用する
- 画面上の選択状態はクエリパラメータまたはモデル属性で保持する
- 選択されたテイスト条件は、検索条件とAND条件で組み合わせる

### 3.3 0件時UI

検索結果が 0 件の場合、以下のメッセージを表示する。

- 該当する商品が見つかりませんでした。別のキーワードでお試しください。

## 4. レスポンシブ対応

- モバイルでは既存の簡易絞り込みUIを維持する
- デスクトップではサイドバー形式の絞り込みUIを維持する
- 検索結果の一覧表示は既存のカードレイアウトを維持する

## 5. アクセシビリティ

- 検索フォームに適切な label / aria-label を付与する
- 0件時メッセージはスクリーンリーダーでも読めるようにする
- 絞り込みボタンおよびモーダル操作は既存UIのアクセシビリティに合わせる
