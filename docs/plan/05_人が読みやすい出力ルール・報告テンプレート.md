# 人が読みやすい出力ルール・報告テンプレート（補助資料）

## このファイルの位置づけ

このファイルは任意の補助資料です。共通ルールの正本は `AI_CODING_RULES.md` 第41章「人が読みやすい出力・報告ルール」です。

**通常の開発作業では、このファイルをAIに毎回渡す必要はありません。** ルール定義書と工程別プロンプトをAIが参照できる状態にしてください。

## 使う場面

次のような場合に限り、このファイルを補助的に参照させます。

- AIの報告形式を新しく設定するとき
- チーム内で報告形式を説明・共有するとき
- 工程別プロンプトに報告項目を追加するとき

## 標準的な報告の並び

1. 結論・作業状態（完了／一部完了／未完了）
2. 重要点の要約
3. 変更内容・問題一覧
4. 確認・テスト結果と根拠
5. 未実施・未解決・残存リスク
6. 人の判断が必要な事項／次の対応

この並びは概要を把握するための目安です。必須の報告項目は、ルール定義書第41章と使用中の工程別プロンプトに従います。工程別プロンプトに指定された報告項目を、この補助資料を理由に削除してはいけません。

## 運用上の注意

- ルールを変更する場合は、まず `AI_CODING_RULES.md` 第41章を更新します。
- 工程別プロンプトには、共通ルールを重複して転記せず、第41章への参照を記載します。
- このファイルに独自の必須ルールを追加しないでください。共通ルールとの二重管理を防ぐためです。
